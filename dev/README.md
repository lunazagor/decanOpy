#`dev/` — Development, Notes, and Archive

This directory contains development materials and archived content that are **not part of the production codebase**. It is retained for historical reference, code prototyping, and research context. None of the contents here are required to run the main `decanOpy` codebase.

---

## Structure

- **`archive/`**  
  Old outputs and scratch data from early experiments and tests. These are preserved for reference and comparison but are no longer used by the main code.

- **`code-dev/`**  
  Jupyter notebooks and temporary scripts used to prototype and test features during earlier stages of development. Some logic here may eventually be modularized into the main codebase.

- **`notes/`**  
  Project-related research notes, relevant data extracts, and documentation that inform the scientific context of the project. These are not related to the code implementation directly but are useful for understanding the broader research goals.

---

##  Guidelines

- This directory is **not version-stable** and is intended for internal use.
- Code or outputs here may not follow style or structure conventions used in the main  package.
- Files may be incomplete, deprecated, inconsistent, or straight-up nonsensical.
